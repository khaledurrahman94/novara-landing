## B. Patterns

Overused (avoid):
- "AI recruiter / assistant / agent that does it all" (Ribbon, Paradox, Workable, Metaview, HeyMilo). Agent-replaces-recruiter is the default and triggers buyer fear.
- Speed/volume math ("hire 5,000 in days", "interview everyone", "24/7, 20+ languages"). Fits frontline staffing, not a generic HR manager.
- Logo wall as first proof; "trusted by X teams"; G2 stars.
- Trust as a footer badge row (SOC 2/GDPR/ISO). Table stakes.
- "Human connection / candidates love it" subheads with no mechanism shown.
- Static dashboard mockup as hero visual.

Genuinely differentiating in the field:
- Ribbon: public bias-audit badge plus live "try an interview" demo.
- HeyMilo: before/after queue visual that quantifies the problem in one frame; "Human in the loop" on the UI itself.
- Sapia: customer outcomes (churn, time to hire) and structured-assessment authority.
- HireVue: explainability statement and fairness studies as evidence.
- BrightHire: product tour with Candidate Fraud as a first-class tab.

Gaps Novara can own (only from its real features):
1. **Show the evidence, not the verdict.** Job Fit Score gives matching/missing criteria plus AI reasoning; interview score is question-level plus overall, with report and recording. Rivals assert "explainable/defensible"; Novara can unfold the why on screen.
2. **Integrity as a named, visible layer.** Tab switching, full-screen exit, copy/paste, camera status, multiple faces, looking away. Rivals say "cheating mitigation" or "40+ signals" without showing them. Own: a timeline of events over the recording.
3. **AI first round inside the ATS, not beside it.** JD drafting, parsing, fit score, AI interview, scheduling, Kanban, career page in one pipeline (Applied to Offered/Rejected). Interviewer startups bolt on to an ATS; Ashby/Workable lack an avatar interviewer.
4. **Recruiter stays the decision-maker, structurally.** Recruiter-added questions alongside AI ones, AI Request and HR Round stages, recruiter moves the cards. HeyMilo only labels it; Novara can show it as workflow.
5. **Calm candidate side under the employer's brand.** Slot-based scheduling, branded career page, avatar interviewer. Uncrowded vs. volume-hiring pitches; speaks to HR managers with a plain demo CTA.
Caution: do not claim bias audit, SOC 2, LL144 or EU compliance unless Vivasoft actually holds it. Do not invent metrics.

## C. Scroll-driven storytelling references

Caveat: WebFetch and search return text only, so motion is NOT verified live except where stated. Items 3-6 are from memory; open each and confirm before copying.

1. Apple AirPods Pro, https://www.apple.com/airpods-pro/ : pinned canvas image-sequence scrub with captions fading over (asset names show start/end frame pairs; inferred). Why: scroll becomes the playhead, so the product feels directed. Build: canvas + preloaded frames, ScrollTrigger pin, scrub ~0.5, end "+=350%", tween frame index with snap:"frame". Recipe: https://gsap.com/community/forums/topic/25188-airpods-image-sequence-animation-using-scrolltrigger/
2. Linear, https://linear.app : app-window mock (issue, agent-opened PR, activity feed) and four lifecycle blocks (intake, planning, AI, review) each with a UI figure. Motion unconfirmed. Why: UI is the visual, ordered as the user's workflow. Build: stacked sections, per-block timeline swapping UI states.
3. Stripe, https://stripe.com : layered gradient/UI compositions with parallax between layers. Build: pinned stage, children at different yPercent in one scrubbed timeline.
4. Vercel, https://vercel.com : pinned feature sections where a diagram/terminal advances stepwise. Build: pin + timeline labels, one step per ~100vh.
5. Raycast, https://www.raycast.com : app-window mock that changes state as you scroll, key-cap reveals. Build: pin, crossfade UI states via autoAlpha.
6. Framer, https://www.framer.com : line-masked headline reveals. Build: SplitText lines, yPercent 100 to 0, stagger.
7. Reference gallery (technique, not a site): https://www.awwwards.com/inspiration/product-scroll-animation-brain-space
